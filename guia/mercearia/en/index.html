AIOS

The Agent Kernel
Python

The AGI Research (Rutgers) project that embeds LLMs inside an operating system layer for agents. Live Multi-Agent Swarm (War Room and Hive)

“Claw” family frameworks usually have one agent that talks with you. ClaudeClaw flips the switch: instead of one, you get a team of specialist agents, each its own Telegram bot, who talk to each other in a live room (the “War Room,” by text or voice) and share a collective brain. Think of a company where each employee logs what they did on a central board—that board is the “Hive Mind,” and ClaudeClaw even renders it as a 3D brain so you can see what the swarm has been up to.

Reflective Loop (The AI That Creates Its Own Skills)

A regular chat responds and forgets. Hermes runs a closed loop: it perceives (perceive), acts (act), reflects (reflect), and saves (save). The reflection step uses a cheap model just to decide what is worth remembering—so memory curates itself. And there is more: when Hermes notices that you have asked for the same sequence of things three times, it writes a new skill (a draft SKILL.md file) and asks for your approval. In other words, the AI learns a new “trick” through use, without you programming anything.

perceiveReads the message
→
actUses tools
→
reflectCheap model curates memory
→
saveMemory + new skill

Who uses it: Hermes (autonomous skill generation + memory curation during reflect). Agent Zero also learns from past solutions, but does not generate SKILL.md on its own.

Agent as an Operating System Process (LLM Kernel)

All the other frameworks run the agent as a “session” or a “loop.” AIOS takes a different approach: it treats each agent as an operating system process, just like the programs running on your computer. There is a kernel (the core) that embeds the LLM, and a Scheduler that decides which agent talks to the model now—so one slow agent does not block all the others. The agent talks to the kernel through syscalls (explicit requests like “call the LLM,” “read memory,” “use a tool”). And the Context Manager can pause an agent, save its state, and resume it later—exactly as an OS does with processes.

Who uses it: AIOS (the only one with a fairness scheduler, context switch, and syscalls). Frameworks like LangChain, AutoGen, and CrewAI can run on top of it.

Glossary: The New Comparison Dimensions

Terms that appear in the comparison table, in plain language:

Live War RoomA room where multiple agents meet in real time (text or voice) to discuss a task.
Hive MindAn “event board” that all agents read and write—a team memory, visualized as a 3D brain.
Reflective loopA perceive→act→reflect→save cycle where the AI decides on its own what to remember.
Autonomous skillA skill the AI writes itself when it detects a repeated pattern, for approval.
Scheduler / FairnessDecides which agent uses the model now, sharing access fairly (FIFO / Round-Robin).
Context switchSave an agent's state and resume it later—pause one to give another a turn.
SyscallAn explicit request from the agent to the kernel (call an LLM, read memory, use a tool)—auditable and schedulable.
MCP ClientA connector that plugs in external tools via Model Context Protocol, without writing code.
Exfiltration guardA filter that scans output and redacts secrets (keys, tokens) before sending.
Hot-reload kill switchA flag that turns off a function in seconds, without restarting the process.

Architecture Patterns

How to structure your framework
Trait-Based Modularity
Each component is defined by a contract. Swap implementations without touching other code. The cleanest extensibility pattern.
ZeroClawIronClaw
Message Bus Architecture
Channels and agents communicate through a central message highway. Clean separation, easy to add new channels.
NanoBot
File-Based Message Queue
Messages are stored as files that move through directories (receiving > processing > sending). Simple, reliable, no database.
TinyClaw
WebSocket Gateway Hub
Central server that all channels connect to through real-time WebSockets. The "control tower" pattern.
OpenClawIronClaw
Dual Database Backend
Use PostgreSQL for production and SQLite for development. Same code, switch with a configuration flag. The best of both worlds.
IronClaw
Project-Based Workspace Isolation
Separate workspaces by client/project. Each has its own memory, secrets, and instructions. No data mixing.
Agent ZeroNanoClaw
Single-Binary Deployment
One file. No dependencies. Copy it anywhere and it works. The simplest deployment story possible.
PicoClawZeroClaw
"Computer as a Tool" Paradigm
Instead of prebuilt integrations, AI writes code on the spot to get things done. Infinitely flexible, no maintenance required.
Agent Zero
Intelligent Model Routing
A complexity classifier sends trivial messages ("ok", "thanks") to a lightweight model and heavy tasks to a full model, saving tokens and time.
ClaudeClaw
Unified Message Gateway
One gateway normalizes CLI, Discord, Slack, WhatsApp, HTTP, and cron into the same Message object — one brain, all the mouths, agent decoupled from the channel.
Hermes
Multi-Backend Deployment (7 backends)
Local, Docker, SSH, Modal, Vercel Sandbox, Singularity/Daytona, and AWS Bedrock AgentCore — from an old laptop running 24/7 to a Firecracker microVM per session.
Hermes
Request Trace (6 hops)
HERMES_TRACE=1 exposes the end-to-end path (webhook -> gateway -> memory FTS5 -> LLM -> tool exec -> response+write) with P50/P95/P99 latencies.
Hermes
100% Declarative Config (config.yaml)
Provider, model, toolsets, MCPs, channels, cron, and system prompts in one versioned YAML file, with dev/prod profiles and ${VAR} for secrets.
Hermes
Agent-as-Process (Fairness Scheduler)
Multiple LLM agents become processes scheduled by a Scheduler with fairness — instead of one long-running agent blocking everyone, the kernel shares access to the LLM (FIFO for 1–2 agents, Round-Robin for 3+).
AIOS
LLM Kernel with Syscall Interface
The LLM is embedded as the kernel core, and the agent communicates through syscalls (LLMCall, MemoryRead/Write, ToolCall, ContextSwitch). Each action becomes an explicit, auditable, schedulable request — the agent's "strace".
AIOS
Context Switch (Snapshot / Restore / Migrate)
Save an agent's full state (memory, plan position, working set) and restore it later — lets you pause a long-running agent to give another a turn, or migrate the agent to another kernel.
AIOS
Kernel + SDK Separation
Two repositories mirroring Linux kernel × glibc: the kernel manages resources (the operator works here), the SDK builds agents (the developer works here). Enables Local/Remote modes and the Agent Hub.
AIOS
Adapter Layer (frameworks run on top)
Execution layer beneath the frameworks: replaces direct LLM calls with a syscall (adapter pattern), so any framework (LangChain/AutoGen/CrewAI/MetaGPT/OpenAGI) inherits scheduling, fairness, and persistence — incremental migration (strangler).

Verdicts: Best for Each Use Case

Quick guide: which framework to choose based on what matters most to you.

"I want the most complete solution"

Complete, polished, with voice, canvas, mobile apps, and 5,700+ plugins. The "iPhone" approach.

Choose: OpenClaw

"I want maximum efficiency"

Smallest memory footprint, fastest startup, runs on $10 hardware. The "sports car" approach.

Choose: ZeroClaw (Rust) or PicoClaw (Go)

"I want to understand every line of code"

Small enough to read all at once. No hidden complexity. The "open book" approach.

Choose: NanoClaw (5.2K lines) or NanoBot (4K lines)

"Security is my #1 priority"

WASM sandboxing, prompt injection defense, leak detection, zero-trust. The "fortress" approach.

Choose: IronClaw

"I want AI teams that collaborate"

Multiple specialized agents handing work off to one another. The "small business" approach.

Choose: TinyClaw or Agent Zero

"I want an AI that learns over time"

Remembers solutions, builds knowledge, gets smarter. The "growing brain" approach.

Choose: Agent Zero

"I mainly use WhatsApp for business"

WhatsApp-first design with group isolation. Simple, secure, purpose-built.

Choose: NanoClaw

"I want to control IoT devices"

Direct control of hardware pins (GPIO, I2C, SPI). AI meets the physical world.

Choose: PicoClaw

"I want the widest choice of AI providers"

Supports 20+ AI providers, easy switching between them, use local models for free.

Choose: ZeroClaw (22+) or Agent Zero (20+)

"I use Python and want to extend it easily"

Python code with clean interfaces for adding channels, tools, and providers.

Choose: NanoBot or Agent Zero

"I need help deciding / researching"

Comprehensive knowledge base with cost calculators, security audits, and 5,700+ plugin examples.

Choose: Awesome OpenClaw (the resource guide)

"I want a TEAM of agents working live"

Multiple specialist agents that meet in real time (text and voice), share a collective brain you can visualize in 3D, and can even join video meetings. The "headquarters" approach.

Choose: ClaudeClaw

"I want an AI that improves itself"

Creates its own skills when it detects repeated patterns and heals its own memory during the reflect step. Local-first, model-agnostic, proactive 24/7. The "agent that grows with you" approach.

Choose: Hermes

"I need many concurrent agents, like an OS"

Schedules agents as processes, with a fairness Scheduler, context switching, and auditable syscalls. Existing frameworks run underneath. The "agent operating system" approach.

Choose: AIOS
