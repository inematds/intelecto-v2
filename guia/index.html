Em resumo

Você quer um assistente de IA só seu, que lembre das suas coisas, mas não quer entregar seus dados nem deixar uma IA solta no computador. O INTELECTO v2 é um assistente pessoal gratuito que você instala no seu computador e conversa com ele pelo terminal ou pelo Telegram. Ele pensa com uma IA que roda na sua máquina (Ollama, sem custo) ou na nuvem, guarda memórias, mexe só numa pasta de trabalho e pede a sua aprovação antes de qualquer comando que não seja só de leitura. Você precisa de Python 3.10 ou mais novo; nada mais é obrigatório.

🔓 Agente com a chave da casa

Um agente que roda comandos sozinho alcança as suas senhas, a internet e os seus arquivos. Basta um erro ou um texto malicioso escondido num site.

🧱 Código que ninguém entende

Os frameworks de agente têm milhares de arquivos. O INTELECTO tem 1.500 linhas, separadas em 8 peças, que dá para ler numa tarde.

As 8 peças

Tudo o que um agente tem, em palavras simples

Cada peça mora numa pasta própria. Você entende o todo sem programar.

💬 1. Canal

Por onde você fala: o terminal ou o Telegram. No Telegram ele só responde a você.

🔁 2. Loop com freio

Pensa, usa uma ferramenta, olha o resultado e responde. No máximo 5 voltas, para não ficar rodando sem fim.

🪪 3. Identidade

Quatro arquivos de texto: quem ele é, como trabalha, quem é você e o que ele já sabe. Você muda escrevendo.

🧠 4. Cérebro

A IA que pensa: uma no seu computador (Ollama, de graça) ou uma na nuvem (OpenRouter, serviço pago que precisa de conta).

📚 5. Memória

Guarda o que você conta e acha de novo pelas palavras, mesmo sem acento. Continua lá amanhã.

🧰 6. Ferramentas

Guardar e buscar memória, ler, gravar e listar arquivos (só na pasta dele) e rodar comando.

🔐 7. Trava e cofre

Decide se um comando pode rodar e guarda senhas cifradas. Tudo o que ele faz fica anotado.

📦 8. Caixa

Se você ligar, cada comando roda numa caixa descartável, sem internet e sem as suas senhas.

Como ele decide

Três respostas para cada comando: roda, pergunta ou recusa

Antes de rodar qualquer comando, a trava olha o que ele faz. O padrão é perguntar: só passa direto o que apenas lê.

roda

Comandos que só olham: listar arquivos, ler um texto, ver a data, ver o espaço do disco.

pergunta

Qualquer outro: gravar, mover, apagar um arquivo, instalar, acessar a internet. Ele pergunta no terminal ou manda "/sim ou /nao" no seu Telegram.

recusa

O que destrói: apagar o disco ou a sua pasta pessoal, formatar, desligar a máquina, baixar e executar script. Nem com o seu OK.

A v1 tinha só uma lista de palavras proibidas: "rm -rf /" era barrado, mas "rm -r -f /" passava. A v2 entende as duas formas e mais 19 variações testadas, e quem não está na lista de leitura precisa da sua aprovação. A lista não é a única proteção: para comando que você não conhece, ligue a caixa.

Como funciona por dentro

O caminho de uma mensagem, do celular à resposta

Exemplo real: você manda "lembre que meu nome é Ana" e, no dia seguinte, "qual meu nome?". Isto é o que acontece dentro do INTELECTO.

1

Chega pelo canal

A mensagem entra pelo terminal ou pelo Telegram. No Telegram, ele confere se quem mandou é você (lista de donos); mensagem de outra pessoa é ignorada e anotada.

2

"Lembre que…" vai direto para a memória

Frase que começa com "lembre que", "guarde" ou "anote" é guardada na hora, sem depender da IA decidir. Por isso até um modelo pequeno lembra. Pergunta (com "?") nunca vira memória.

3

Monta o contexto

Junta os arquivos de identidade (quem ele é, como trabalha, quem é você), as memórias que combinam com a pergunta ("nome" acha "meu nome é Ana") e as últimas conversas.

4

O cérebro pensa

Tudo isso vai para a IA (no seu computador ou na nuvem). Ela responde ou pede uma ferramenta: guardar, buscar, ler um arquivo, rodar um comando.

5

A ferramenta passa pela trava

Se for comando, a trava decide: roda, pergunta a você ou recusa. Aprovado, ele roda na pasta de trabalho, ou na caixa sem internet se você ligou. O resultado volta para a IA, no máximo 5 voltas.

6

Responde e anota

Você recebe a resposta, e tudo o que ele fez (comando, ferramenta, memória, erro) fica numa linha da auditoria, para você conferir depois.

Parte técnica

O kit: para quem quer instalar e usar

Daqui para baixo é a parte técnica: instalar, configurar e rodar. Você não precisa desta parte para entender o que está acima.

O que é

Um pacote Python, sem dependências

Só a biblioteca padrão do Python. O pacote cryptography é opcional (cofre com Fernet).

🐍 python3 -m intelecto

Uma linha de comando com 8 subcomandos: conversar, demo, telegram, configurar, cofre, memoria, auditoria e verificar.

🗂️ ~/.intelecto2/

Tudo do assistente fica numa pasta: config, memória, identidade, pasta de trabalho, auditoria e cofre. Troque com INTELECTO_HOME.

✅ 68 testes

python3 -m pytest -q. Nenhum teste chama API de verdade.

Como funciona

O caminho de uma mensagem

Você (terminal ou Telegram)→ Identidade + memórias que casam→ Cérebro decide→ Ferramenta → trava → aprovação→ Executor local ou caixa→ Resposta + auditoria
Pré-requisitos

O que precisa

Python 3.10+ e git

O Python já vem no Linux e no macOS recente. O git (o programa que baixa o projeto) pode faltar numa máquina nova.

python3 --version && git --version
sudo apt install -y git   # Ubuntu, se faltar o git
xcode-select --install    # macOS, se faltar o git

Ollama (cérebro local)

De graça, em ollama.com. O modelo testado pede uma placa de vídeo boa; o llama3.2 roda em máquina simples: usa pouco as ferramentas, mas lembra o que você pede com "lembre que…".

ollama pull qwen3.6:35b-a3b
ollama pull llama3.2  # mais leve

Docker (só para a caixa)

Opcional. Só se você quiser rodar os comandos numa caixa sem internet.

docker run --rm hello-world
Guia de uso · passo a passo

Do zero ao seu Jarvis em 10 minutos

1

Baixe e veja funcionando

A demonstração usa um cérebro de mentira: roda sem internet e sem modelo.

cd ~ && git clone https://github.com/inematds/intelecto-v2 && cd intelecto-v2
python3 -m intelecto demo
2

Configure

Pergunta o nome, a personalidade, o cérebro, o modelo, onde rodar comandos (local ou caixa) e a aprovação. Enter mantém o valor sugerido.

  • Modelo: ele mostra os modelos que você já baixou no Ollama e sugere um deles. Se aparecer um que você não tem, digite o nome do que baixou (ex.: llama3.2).
  • Aprovação: perigosos (padrão) faz o que está em "Como ele decide"; sempre pergunta até para listar arquivos; nunca não pergunta nada e só deixa rodar o que apenas lê.
python3 -m intelecto configurar
3

Dê a sua cara

Edite os 4 arquivos de identidade. Cada linha que começa com "- " no MEMORY.md vira uma memória na primeira vez.

nano ~/.intelecto2/identidade/USER.md     # quem é você
nano ~/.intelecto2/identidade/AGENTS.md   # regras de trabalho (memória, ferramentas)
nano ~/.intelecto2/identidade/SOUL.md     # jeito de ser
nano ~/.intelecto2/identidade/MEMORY.md   # fatos iniciais
4

Confira e converse

python3 -m intelecto verificar   # → tudo certo
python3 -m intelecto             # conversa no terminal; 'sair' para terminar

Se aparecer [FALTA] no modelo, baixe-o com ollama pull <modelo> ou rode o configurar e escolha um dos que você já tem.

5

Telegram (opcional)

No Telegram, abra o @BotFather, mande /newbot, escolha um nome e copie o token que ele responde (o código secreto do seu bot, do tipo 123456:ABC…). Guarde esse token no cofre. Ligue o bot, mande /id para ele e ponha o número que ele responder no configurar (pergunta dos ids do Telegram; nas outras perguntas, só aperte Enter). Sem dono configurado, ele só responde ao /id.

python3 -m intelecto cofre guardar telegram   # cola o token; não aparece na tela
python3 -m intelecto telegram                 # mande /id no bot, depois Ctrl+C
python3 -m intelecto configurar               # coloque o seu id
python3 -m intelecto telegram
6

Ligar sozinho quando o computador ligar (opcional)

# Linux (systemd do usuário; ajuste a pasta no arquivo se não clonou em ~/intelecto-v2)
mkdir -p ~/.config/systemd/user
cp servico/intelecto-telegram.service ~/.config/systemd/user/
systemctl --user daemon-reload && systemctl --user enable --now intelecto-telegram
# macOS: troque SEU_USUARIO em servico/club.inema.intelecto.plist e copie para ~/Library/LaunchAgents/
7

Comandos na caixa (opcional)

Com Docker, cada comando aprovado roda num container sem rede, só com a pasta de trabalho.

docker pull python:3.12-slim
python3 -m intelecto conversar --executor caixa   # ou executor caixa no configurar
8

OpenRouter, se quiser um modelo na nuvem

A chave vai no cofre, nunca no config. Cada mensagem custa conforme o modelo escolhido.

python3 -m intelecto cofre guardar openrouter
python3 -m intelecto conversar --provedor openrouter --modelo anthropic/claude-sonnet-5.5
9

Veja o que ele fez

python3 -m intelecto memoria           # últimas memórias
python3 -m intelecto memoria cachorro  # busca
python3 -m intelecto auditoria -n 20   # comandos e ferramentas, com o que rodou e o que não rodou
Saída real

A demonstração, como sai na tela

python3 -m intelecto demo

intelecto> Feito. Resultado de rodar_comando: [local, saída 0]
você> rode: echo teste > nota.txt
intelecto> Feito. Resultado de rodar_comando: não rodei: o dono não aprovou

Parte final

Como a caixa-do-agente melhora o seu projeto

O INTELECTO protege o que o assistente faz. A caixa-do-agente protege o projeto enquanto você, o Claude Code ou o Codex mexem nele.

Em palavras simples: uma sala fechada

Quando você deixa um agente de IA mexer no computador sozinho, ele alcança as suas senhas (.env, chaves), a internet e os seus arquivos de verdade. A caixa-do-agente faz o trabalho numa sala fechada, em 3 passos:

1. Cria

Faz uma cópia do projeto numa pasta temporária e deixa de fora as senhas e as chaves.

2. Roda

O comando roda na cópia, num container (uma caixa isolada dentro do seu computador) sem internet, com limite de memória, de processador e de tempo.

3. Destrói

Mostra o que mudou num arquivo .patch (a lista das mudanças), apaga o container e a cópia. O original só muda se você aplicar.

É como deixar o pedreiro trabalhar numa maquete da sua casa, sem a chave do cofre: no fim você olha o que ele fez e decide se faz igual na casa de verdade. A segunda ferramenta do kit, o auditor, só lê e dá uma nota de 0 a 10 para a proteção de quem programa no projeto.

O que aconteceu quando passamos o INTELECTO v2 pela caixa

📦 Os testes dentro da caixa

O arquivo de senha (.env) ficou fora da cópia, 67 testes passaram e 1 foi pulado (o que precisa de Docker, que não existe lá dentro) e 0 arquivos mudaram. Como a caixa não tem internet, o programa de testes (pytest) vai numa imagem preparada antes (caixa/Dockerfile).

📊 A nota do auditor

4,2→7,5de 10

O auditor olha o projeto e as ferramentas de programação que você usa nele (Claude Code, Codex). A nota subiu com duas mudanças: tiramos o arquivo de senha (.env) de dentro do projeto e pusemos um arquivo de regras para os agentes (CLAUDE.md).

Faltou a camada "caixa": no computador onde testamos, o Claude Code e o Codex estão configurados para rodar sem isolamento. Isso é configuração de cada computador, então rode o auditor no seu para ver a sua nota. Para fechar essa camada, rode o seu agente por dentro do caixa.sh.

# 1. imagem com o pytest (a caixa não tem internet para instalar nada)
docker build -t intelecto-v2-testes caixa/
# 2. os testes numa cópia sem .env, sem rede, que se apaga no fim
~/caixa-do-agente/caixa.sh ~/intelecto-v2 --imagem intelecto-v2-testes -- python3 -m pytest -q -p no:cacheprovider
# 3. a nota (só lê, não muda nada)
python3 ~/caixa-do-agente/auditar.py ~/intelecto-v2

Para ter a caixa: git clone https://github.com/inematds/caixa-do-agente ~/caixa-do-agente (precisa de Docker e Python 3).
